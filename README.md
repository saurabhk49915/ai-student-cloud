# AI Student Cloud

Hackathon-ready frontend starter for the AWS Zero to Shipped project.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Next AWS integration

1. Add AWS Amplify Gen 2.
2. Configure Cognito authentication.
3. Add per-user data with Amplify Data.
4. Add S3 file storage.
5. Connect the AI layer (for example Amazon Bedrock through a secure backend function).
6. Deploy with Amplify Hosting.

The current UI intentionally uses mock interactions so the frontend can be reviewed before cloud credentials are configured.
